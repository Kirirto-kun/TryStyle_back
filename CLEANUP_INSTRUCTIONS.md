# Инструкция по очистке базы данных и перезапуску скрапера

## Проблема
Цены парсились неправильно из-за ошибки в regex. Вместо правильных цен получались неправильные значения.

## Решение

### 1. Очистка базы данных

#### Вариант 1: Удалить только товары
```bash
python clear_qazaq_products.py
```

#### Вариант 2: Удалить магазин полностью
```bash
python clear_qazaq_products.py --store
```

### 2. Проверка исправленного парсинга цен

```bash
python test_price_parsing.py
```

Ожидаемый результат:
```
Тест 6: <div class="catalog_item__price">12800₸<span>16000₸</span></div>
  ✅ Результат: 12800₸ (скидка с 16000₸)
```

### 3. Перезапуск скрапера

#### В Docker:
```bash
docker-compose down
docker-compose up --build
```

#### Ручной запуск:
```bash
python qazaq_republic_scraper.py
```

## Что было исправлено

### ❌ Старый код (неправильный):
```python
prices = re.findall(r'(\d+)', clean_text)
```

### ✅ Новый код (правильный):
```python
prices = re.findall(r'\d+', clean_text)
```

### Разница:
- `(\d+)` - находит каждую цифру отдельно: 1, 2, 8, 0, 0, 1, 6, 0, 0, 0
- `\d+` - находит полные числа: 12800, 16000

## Результат

После исправления:
- `12800₸<span>16000₸</span>` → `12800₸` (скидка с `16000₸`)
- `11000₸<span>22000₸</span>` → `11000₸` (скидка с `22000₸`)
- `24000₸` → `24000₸` (без скидки)
