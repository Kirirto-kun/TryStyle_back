# Qazaq Republic Scraper

Скрипт для парсинга товаров с сайта Qazaq Republic и добавления их в базу данных с AI-анализом изображений.

## Возможности

- Парсинг товаров с сайта https://qazaqrepublic.com/ru/shop
- Автоматическое скачивание изображений товаров
- AI-анализ изображений для извлечения характеристик
- Создание товаров в базе данных с полной информацией
- Автоматическое создание магазина "Qazaq Republic"
- Подробное логирование процесса
- **Правильный парсинг цен со скидками** (исправлено)
- **Обработка всех товаров на странице** (без ограничений)

## Структура скрипта

### Основные компоненты

1. **QazaqRepublicScraper** - основной класс скрипта
2. **parse_shop_page()** - парсинг HTML страницы магазина
3. **download_image()** - скачивание изображений
4. **process_image_with_ai()** - AI-анализ изображений
5. **create_qazaq_republic_store()** - создание/поиск магазина
6. **process_product()** - обработка одного товара
7. **_parse_price_from_html()** - правильный парсинг цен с HTML тегами

### Извлекаемые данные

- **Название товара** - из элемента `catalog_item__name`
- **Цена** - из элемента `catalog_item__price` (поддерживает скидки в span тегах)
- **Изображение** - из `img` тега
- **Ссылка на товар** - из атрибута `href`

### Поддерживаемые форматы цен

✅ **Обычная цена:** `11000₸`
✅ **Цена со скидкой:** `11000₸<span>22000₸</span>`
✅ **Цена с пробелами:** `11 000₸`
✅ **Скидка с пробелами:** `11 000₸<span>22 000₸</span>`

### AI-анализ изображений

Скрипт использует существующую функцию `analyze_image()` для извлечения:
- Категории товара
- Характеристик (цвет, материал, фасон и т.д.)
- Описательного названия

## Логирование

Скрипт создает два лога:
- **Консольный вывод** - для мониторинга в реальном времени
- **Файл qazaq_scraper.log** - для детального анализа

## Обработка ошибок

- Продолжение работы при ошибках отдельных товаров
- Откат транзакций при ошибках создания товаров
- Подробное логирование всех ошибок

## Расширение функциональности

Для добавления новых возможностей:

1. **Парсинг дополнительных страниц** - измените `SHOP_URL`
2. **Извлечение дополнительных данных** - модифицируйте `_extract_product_data()`
3. **Другой AI-анализ** - замените `analyze_image()` на другую функцию
4. **Другие магазины** - создайте новый класс скрапера
